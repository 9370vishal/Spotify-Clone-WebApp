# 🎵 Spotify Clone App

## 📌 Project Overview

The Spotify Clone App is a music player web application inspired by Spotify. It provides a simple and interactive interface where users can browse songs, play music, control playback, and enjoy a music-listening experience.

This project is developed using **HTML5, CSS3, and JavaScript** to demonstrate frontend web development skills.

## 🚀 Features

- 🎧 Music player interface inspired by Spotify
- ▶️ Play and pause music
- ⏭️ Next and previous song controls
- 🎚️ Volume control
- ⏱️ Music progress bar and seek functionality
- 🎶 Song and playlist display
- 📱 Responsive user interface
- 🎨 Modern design with a dark theme
- 🔊 Audio playback using JavaScript

## 🛠️ Technologies Used

- **HTML5:** Structure of the web application
- **CSS3:** Styling, layouts, animations, and responsive design
- **JavaScript (JS):** Music playback, event handling, and interactive controls
- **VS Code:** Code editor
- **Git and GitHub:** Version control and project hosting

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Make sure the HTML file correctly links to `style.css` and `script.js`.

4. Add audio files that you have permission to use to the `songs/` directory.

5. Open `index.html` in your browser or use the Live Server extension in VS Code.

## ▶️ How to Use

1. Launch the website in your browser.
2. Browse the available songs or playlists.
3. Click the play button to start music playback.
4. Use pause, next, and previous controls to manage playback.
5. Adjust the volume or move the progress bar to seek through a song.
